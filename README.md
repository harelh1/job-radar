# 📡 Job Radar – התראות על משרות חדשות

מערכת שסורקת את אתרי הקריירה של חברות אלקטרו-אופטיקה, מוליכים למחצה וביטחוניות בישראל **כל ~2 דקות**,
נותנת לכל משרה **אחוז התאמה** לפרופיל שלי, ושולחת **הודעת טלגרם** ברגע שעולה משרה מתאימה.

- **סורק** (`scanner/`) – Python, רץ בענן של GitHub (GitHub Actions) בחינם, גם כשהמחשב כבוי.
- **אתר** (`docs/`) – דשבורד עם כל המשרות, סינון לפי אחוז התאמה / סטודנט / חברה (GitHub Pages).
- **בוט טלגרם** – התראות + פקודות להוספת חברות.

---

## הקמה (פעם אחת, ~15 דקות)

### 1. בוט טלגרם
1. בטלגרם, פתח צ'אט עם **@BotFather** ← שלח `/newbot` ← תן שם (למשל `Harel Job Radar`) ושם משתמש שנגמר ב-`bot`.
2. BotFather ישלח **טוקן** (נראה כמו `123456:ABC-...`). שמור אותו – זה סוד, אל תשתף.
3. פתח צ'אט עם הבוט החדש ושלח לו `/start`.

### 2. חשבון ו-Repository ב-GitHub
1. היכנס/הירשם ב-[github.com](https://github.com).
2. צור Repository חדש: **New** ← שם `job-radar` ← **Public** (חשוב: ב-Public הדקות של GitHub Actions בחינם וללא הגבלה) ← **Create**.
3. בעמוד הריק לחץ **uploading an existing file**, וגרור לשם את **כל התוכן** של התיקייה `job-radar`
   (כולל התיקייה `.github`) ← **Commit changes**.

> ⚠️ ה-Repository ציבורי: רואים בו את רשימת החברות והמשרות, לא את הטוקן ולא פרטים אישיים.

### 3. סודות (Secrets)
ב-Repository: **Settings ← Secrets and variables ← Actions ← New repository secret**:
- `TELEGRAM_BOT_TOKEN` = הטוקן מ-BotFather.
- `TELEGRAM_CHAT_ID` = ה-Chat ID שלך. איך מוצאים: הוסף קודם רק את הטוקן, הפעל סריקה (שלב 4),
  והבוט יענה לך בטלגרם עם ה-Chat ID. אז הוסף אותו כ-Secret שני.

### 4. הפעלה
1. לשונית **Actions** ← אם מופיע כפתור הפעלה ירוק – לחץ עליו.
2. בחר **Job Radar scan** ← **Run workflow**. מכאן הוא רץ לבד כל כמה דקות.
3. אחרי הסריקה הראשונה תקבל בטלגרם הודעת "Job Radar פעיל!" עם המשרות הכי מתאימות.

### 5. האתר
**Settings ← Pages** ← Source: **Deploy from a branch** ← Branch: `main`, תיקייה: `/docs` ← **Save**.
אחרי דקה-שתיים האתר יהיה בכתובת `https://<שם-המשתמש>.github.io/job-radar/` (שמור במועדפים בטלפון).

## שימוש

| בטלגרם | מה זה עושה |
|---|---|
| `/add Camtek` | מוסיף חברה – הבוט מחפש לבד את עמוד המשרות שלה |
| `/add Camtek https://...` | אם לא מצא – שלח קישור לעמוד המשרות |
| `/remove Camtek` | מסיר חברה |
| `/list` | רשימת החברות ומספר המשרות |
| `/top` | 10 המשרות הכי מתאימות עכשיו |
| `/min 60` | התראה רק על משרות עם 60%+ התאמה (ברירת מחדל 55%) |

חברות שהבוט לא הצליח לזהות נשמרות ב"ממתינות" – אפשר לבקש מ-Claude להוסיף אותן ידנית.

## איך מחושב אחוז ההתאמה
`scanner/scoring.py` – לפי הקורות חיים: תחום התפקיד בכותרת (אלקטרו-אופטיקה, אופטיקה, לייזרים, מטרולוגיה, פיזיקה, דימות…),
מילות מפתח בתיאור (Zemax, MATLAB, Python, אינטרפרומטריה, עבודת מעבדה), התאמה לסטודנט/ג'וניור,
ומינוס על משרות בכירות, דרישת שנות ניסיון, תארים מתקדמים, ותחומים לא קשורים. ליד כל משרה כתוב *למה* קיבלה את הציון.

## מהירות
GitHub מפעיל את הסריקה כל ~5 דקות (לפעמים באיחור), וכל הפעלה סורקת שוב ושוב כל ~2 דקות במשך 9 דקות.
בפועל: התראה בדרך כלל תוך 2–10 דקות מרגע שהמשרה עולה לאתר החברה.
